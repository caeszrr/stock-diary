# src/v2 設計憲法(DESIGN.md)

全部 v2 元件遵守。自我審查(M10)逐條對照本檔。

## 1. 年長活躍交易者優先
- 基準字級 **≥ 18px**(`--fs-base: 18px`),關鍵數字用 `--fs-num`(22px)或
  `--fs-num-lg`(28px)加大。
- 所有數字 `font-variant-numeric: tabular-nums`(token:`.num` 工具類)。
- 觸控目標 **≥ 44px**(按鈕/輸入框最小高度 `--tap: 44px`)。
- 文字對比達 WCAG AA(深淺色皆驗)。

## 2. 台股色規
- **紅漲綠跌**。唯一來源 = v1 既有全域 token `--up` / `--down`
  (`src/style.css` `:root`,含深色模式)。v2 一律 `var(--up)` / `var(--down)`,
  **禁止硬編碼**任何紅綠色碼。

## 3. Tokens 一檔(`src/v2/tokens.css`)
- 間距:4 / 8 / 12 / 16 / 24 / 32(`--sp-1`…`--sp-6`)。
- 字階:18 / 20 / 22 / 28 / 34(base、標題、關鍵數字、大數字)。
- 圓角:`--r-sm: 8px`、`--r-md: 12px`;陰影:`--shadow-card` 一種。
- 色彩:中性灰階 + `--up` 紅 + `--down` 綠 + 一個強調色(沿用 v1
  `--accent` 紫)。**不准超過。**

## 4. 卡片解剖律
每張卡 = 標題 + 關鍵數字 + **一個**主要動作 + **一個**「⋯」溢出選單。
禁孤兒按鈕、禁漂浮功能(任何動作必須屬於某張卡或頁級主動作)。

## 5. 擺放律
- 算出來的(費用、損益兩平、風報比、距離 %)→ 卡片本體。
- 推論的(建議、判讀)→ `AiSlot`(今晚 = 預設隱藏的摺疊占位,不接後端,
  禁 AI/LLM import)。

## 6. 空狀態一等公民
每頁、每卡的空狀態 = 一句引導 + 一個主要動作。禁空白死路。

## 7. 過去日期 = 整頁唯讀
輸入全部 `disabled` + 頁頂唯讀提示條。判定基準:Asia/Taipei 今日。

## 8. 誠實資料
「現價」一律標示「最近收盤」與資料日期;休市/開盤前無跳動屬正常。
缺資料顯示空狀態,絕不捏造(repo 鐵律)。
